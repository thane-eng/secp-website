Apply for SECP Certification

The process is designed to be straightforward. Experienced coaches can typically complete the application in a few hours and receive a decision within 1–2 weeks.

How the Process Works

  1. Submit materials + application fee — Experience summary, 2–3 references, 1–2 anonymized case summaries, ethics commitment, and proof of liability insurance. Application fee: $175 (non-refundable).
  2. Review — We review the portfolio and contact references. Typical decision time is 1–2 weeks.
  3. Decision — If approved, you pay the accreditation fee and are added to the public directory. If not approved, you receive feedback.
  4. Accreditation fee — $375 (due only if approved). Total investment: $550.
  5. Directory listing — Your name and credential appear in the public SECP directory.

Application fee: $175 (due at submission)

Accreditation fee: $375 (due only if approved)

Total: $550

Annual renewal: $295 (keeps directory listing active)

No multi-month training required. Experience is the primary criterion.
